Privacy policy

Last updated: 7 November 2026.

fabrica-youtube is a private tool used only by the owner of the YouTube channels it connects to. This policy explains what it accesses and what it does with it.

What it accesses

With the owner's permission through Google sign-in, it reads read-only YouTube Analytics and YouTube Data for the owner's own channels: views, watch time, audience retention, traffic sources and similar video statistics. It requests read-only access and cannot upload, edit or delete videos, comments or channel settings.

How the data is used

The data is used only to review how the owner's videos perform and to plan future videos. It is stored on the owner's own computer and is not sold, shared with third parties or used for advertising.

Retention and removal

Statistics are kept on the owner's computer while they are useful for that purpose. Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions), after which the tool can no longer read any data.

Google API Services

fabrica-youtube uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
